To create simple terminal based games for supporting memory, identity, and daily orientation.
1) *Identity Room* 👇

A safe, personalized virtual room that contains items linked to the player’s life, such as family names, favorite songs, hometown landmarks, and major events. Tapping items unlocks brief memory prompts and helps rebuild autobiographical continuity.
2) *Daily Anchor* 👇
A routine game that trains orientation to time, place, and recent activities. It could reward users for correctly identifying the day, upcoming tasks, familiar faces, and repeated daily patterns, which may reduce confusion and support independence
